# “大全助你选金枕榴莲”移动端设计 Token

- 视觉状态：已由用户于 2026-08-30 确认。
- 已批准概念图：[`durian-picker-mobile-concept.png`](./durian-picker-mobile-concept.png)。
- 实现基线：微信内竖屏 H5，优先以 390px 宽视口编码；视觉应真实、专业、接地气，避免科技大屏感。
- 产品边界：仅呈现照片可见外观证据；不增加登录、支付、会员或准确率承诺。

## 4. 图片、编号与候选标签

- 合照预览比例：`4 / 3`，使用 `object-fit: cover`；拍摄原图不得被前端裁切后改变分析坐标基准。
- 首屏主视觉：`4 / 3`，圆角 `20px`，可使用已批准的静态插画/照片，不用于伪装真实检测结果。
- 候选缩略图：`1 / 1`，圆角 `10px`，使用 `object-fit: cover`。
- 补拍三格：`1 / 1.15`，圆角 `14px`；已完成图层使用 `rgba(63, 125, 22, 0.16)`，右上显示 `24px` 绿色对勾。
- 编号框：`2px solid #FFFFFF`，圆角 `4px`，内阴影 `0 0 0 1px rgba(31, 38, 24, 0.45)`；编号标签定位在框左上角，最小高 `24px`、水平内边距 `7px`、圆角 `6px`、背景 `#27550E`、文字 `#FFFFFF`、`13px/1.25/700`。优先候选可额外显示 `2px solid #F3BD33` 外描边；风险目标标签背景为 `#D85A21`。
- 候选状态标签：最小高 `22px`、圆角 `999px`、`12px/1.25/700`、水平内边距 `8px`；不得覆盖果柄、裂口等需要阅读的图像证据。

## 5. 控件与模态框

- 主按钮：高 `52px`，圆角 `14px`，背景 `#3F7D16`，文字白色 `17px/600`；按下为 `#27550E`，禁用为 `#B8BDAF`。
- 次按钮：高 `44px`，圆角 `12px`，白底，`1px solid #3F7D16`，文字 `#3F7D16`。
- 卡片：白底，`1px solid #E5D9BB`，圆角 `14px`，内边距 `16px`；初筛主候选可采用 `#FFF9E8` 背景与 `#F3BD33` 边框。
- 额度耗尽模态框：宽 `calc(100vw - 40px)`，最大 `360px`，圆角 `20px`，内边距 `24px 20px`，使用 `--shadow-modal`；标题居中。
- 二维码容器：`224px × 224px`，最大宽度 `100%`，居中，白色背景与 `1px solid #E5D9BB`；真实二维码图片为 `img`，宽高 `100%`，`object-fit: contain`，不可裁切、不可加滤镜、不可转成 Canvas 或 CSS 背景。下方显示“长按识别二维码添加好友”。

## 6. 动效与可访问性

- 普通淡入/状态切换：`180ms ease-out`。
- 卡片进入与模态框：`220ms cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 识别中的图标环：`900ms linear infinite`，只表示处理中，不显示虚假的百分比进度。
- `@media (prefers-reduced-motion: reduce)` 下：所有非必要 transition 时长设为 `0ms`，识别环停止，保留明确的文字“正在识别可见榴莲…”。
- 文字与背景最低对比度按 WCAG AA 处理；焦点环使用 `0 0 0 3px rgba(63, 125, 22, 0.35)`。

## 7. 六屏逐屏实现清单

### 屏 1：首页

- 顶部品牌标题“大全助你选金枕榴莲”、副标题“泰国金枕外观 AI 初筛演示版”。
- 显示剩余体验次数胶囊，例如“剩余体验 5 次”。
- 使用温暖的榴莲主视觉，主按钮“拍照开始选榴莲”，附相机图标。
- 固定提示：“随手拍，最多 20 颗”；说明遮挡严重或未识别的榴莲不会被编号。
- 底部署名：“由大全提供 · 实体 AI 赋能陪做教练”。

### 屏 2：合照选择与分析等待

- 显示用户选定的合照 `4:3` 预览，不能替换为虚构检测图。
- 等待卡显示“正在识别可见榴莲…”，下列三步：识别榴莲、自动编号、筛选候选。
- 仅可使用循环图标和文字状态，禁止百分比、倒计时、虚构“准确率”。

### 屏 3：初筛编号结果

- 原图上只绘制服务端返回并验证过的目标编号框；未识别目标不编号。
- 显示“识别到 X 颗”及未参与识别说明。
- 候选清单显示 3～5 颗（实际不足则按实际数量），每项给出可见外观优点、风险和证据充分度。
- 用户最多选择 3 颗，按钮为“选择候选继续补拍”。

### 屏 4：候选补拍向导

- 标题“候选补拍 · X号”，顶部返回按钮。
- 提示“请按要求补拍以下部位（N/3）”。
- 三个相机位固定为：果柄、侧面和果刺、底部果瓣线；展示已完成/待拍/拍摄中状态。
- 三张齐全后才允许提交该候选；不添加对内部品质的判断引导。

### 屏 5：最终推荐

- 标题“外观初筛建议”，第一推荐、备选 1、备选 2 依次展示，最多 3 颗。
- 每项仅显示“可见证据”“风险提示”“证据充分度”和同批候选的“外观推荐指数”。
- 保留红色固定声明：“仅根据照片中可见外观特征提供初筛建议”。
- 主要按钮“保存或分享结果”。

### 屏 6：额度耗尽弹窗

- 深色半透明遮罩覆盖当前页面，不能阻止真正二维码显示。
- 标题“免费体验额度已用完”。
- 文案：“想获得更多额度，可添加微信 daquan088”。
- 按钮“复制微信号 daquan088”，复制成功有简短确认反馈。
- 显示完整、未裁切的真实二维码与“长按识别二维码添加好友”。

图标采用同一套线性图标（例如 Lucide 风格），默认描边 `2px`：相机、相册/上传、识别定位、编号标签、候选清单、箭头、返回、对勾、复制、分享、保存/下载、关闭、重试、信息、警告。图标仅辅助文字，重要操作不可只有图标。

## 9. 不可变实现约束

1. 额度耗尽二维码必须是浏览器中完整可见的真实 `<img>` 元素，来源为 `public/assets/daquan-wechat-qr.jpg`；不得使用 Canvas、CSS `background-image`、SVG 重绘或生成式替代图，以保留微信长按识别能力。
2. 不修改用户提供的二维码源文件；项目内素材只是独立副本。
3. 不做登录、支付、会员、历史记录或“准确率/甜度/果肉比例”承诺。
4. 所有 AI 文字作为纯文本渲染；风险、证据和限制必须与固定能力声明共同出现。
